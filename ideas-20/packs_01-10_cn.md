## 1. 营地边缘热浪庇护

### 挑战
悉尼灰头狐蝠（*Pteropus poliocephalus*，EPBC 易危）营地在约 ≥42 °C 时大量死亡，幼蝠与哺乳雌性尤其如此（NSW 热应激指引；Welbergen 一类文献；2026 年 1 月东海岸死亡事件）。这里要解决的不是黑暗，是 **热和荫**。本学期 **不** 装进活营地。

### 非人类利益相关者
- **主 — 幼蝠 / 依赖个体。** 越过阈值时需要蒸发冷却和遮荫。
- **次 — 成体。** 营地不被打扰；装置不能变成游客喷雾。
- **再次 — 栖树。** 不能被浇到腐烂；喷雾短、定向、默认 **关**。

### 构想（行为）
挂在树上的 PETG「叶子」（校园热箱）。

1. `IDLE` — 传感器开，喷雾关，叶对气流打开。
2. `FORECAST_HEAT` — 气象局预报峰值将越阈 → 叶 **在峰值前** 折起遮荫。
3. `LIVE_HEAT` — DHT22 + 红外冠层温度在带内 → 喷雾 PWM，短脉冲。
4. `RECOVER` — 温度回落 → 喷雾关，叶复原。
5. `FAULT` — 水箱空 / 泵堵 → 底面灯只给 **人** 看。
6. `INHIBIT_COOL` — 低于阈值，什么都不做。

### 一句架构
空气 + 冠层热 + 预报 → ESP32-S3 → 折叶，且 **仅在现场热时** 脉冲泵。默认 **关**。失效 **关断**。

```
 世界     气温 / 湿度              冠层表面              6 小时预报 / 钟
              │                      │                      │
 感知      DHT22                  MLX90614（或照度）     WiFi → 气象局 / Open-Meteo
              │                      │                      │
 融合                    ESP32-S3 / ESP-IDF  六态
              │                      │                      │
 执行      MOSFET + 5 V 泵        MG90S 叶荫             维护琥珀灯
 电源      USB 台供 / 18650       重力水箱 + 浮子
 演示      热风枪 / 热箱           绝不用活营地
```

### 数据流

| 从 | 到 | 信号 | 用途 |
|---|---|---|---|
| DHT22 | MCU 1-wire | T_air, RH | 现场热带；湿球近似 |
| MLX90614 | MCU I2C | T_canopy | 「栖位模型」表面，不是空气 |
| 气象局 / Open-Meteo | WiFi → NVS | 未来 6 h 最高温、热浪旗 | 前馈遮荫 |
| 浮子 / 空罐 | GPIO | tank_ok | 禁止泵 |
| 状态机 | MOSFET | PWM，2 s 开 / 20 s 关 | 喷雾；绝不连续 |
| 状态机 | MG90S | 折叠 0–90° | 峰值前遮荫 |
| 状态机 | 琥珀 | 慢脉冲 | 只给人 |

### 硬件栈

| 层 | 零件 | 总线 / 说明 |
|---|---|---|
| 外壳 | Fusion 悬挂叶、树皮色 PETG、水箱袋、喷嘴对准 **假** 冠层 | 形态是叶子，不是电器盒 |
| 计算 | ESP32-S3 DevKit | 共用引脚 |
| 感知 | DHT22（GPIO 4）；MLX90614 走 I2C，红外来不及再用 BH1750 | 红外更好 — 阳光下 DHT 会虚高；探头要遮 |
| 执行 | 5 V 泵 + N-MOSFET + 续流；MG90S；底面琥珀 | GPIO 6 泵，GPIO 7 舵机，GPIO 5 琥珀 |
| 水 | 0.5–1 L 箱，重力，浮子 GPIO 12 | 电子在水箱 **上方** |
| 网 | WiFi STA | 气象局 / Open-Meteo；缓存 6 h |

**引脚。** 走共用表。不需要 LD2410（存在不是这条故事）。GPIO 17/18 空着。

**电源。** USB 2 A。泵占大头。不要从 3.3 V 脚给泵供电。

**BOM 差额。** 5 V 泵、水箱、软管、MLX90614、浮子。不要摄像头。

**不要买。** 「给 Wolli Creek 用的营地喷淋」。NPWS / 伦理。不要活栖位。

### 软件栈

任务：`task_climate` 1 s · `task_ir` 500 ms · `task_forecast` 10 min · `task_fsm` 50 ms · `task_actuate` 20 ms。

额外 `ctx`：`t_air`、`rh`、`t_canopy`、`t_max_6h`、`tank_ok`、`burst_remaining_ms`。

滞后：进入 `LIVE_HEAT` 当 T_canopy ≥ 38 °C **且** T_air ≥ 35 °C（演示阈值 — 报告引用营地 42 °C 科学，然后写明模型更凉）。退出低 2 °C。预报遮荫：模拟 T_max_6h ≥ 36 °C / 叙事可按 40 °C 缩放。

```
                 6h 最高温高
      IDLE ──────────────────────► FORECAST_HEAT（叶折，泵仍关）
        │                              │
        │  现场带                       │ 现场带
        ▼                              ▼
   INHIBIT_COOL ◄── 变凉 ── LIVE_HEAT（tank_ok 时 PWM 脉冲）
        ▲                              │
        └──────── RECOVER ─────────────┘  （泵关，叶保持再打开）

   任一 + !tank_ok 或堵转 ──► FAULT（琥珀，泵强制关）
   api_ok false ──► 不进 FORECAST_HEAT；除非现场带否则停 IDLE
                    失效关断：预报缺失绝不喷雾。
```

| 状态 | 叶 | 泵 | 规则 |
|---|---|---|---|
| `IDLE` | 开 | 关 | 默认 |
| `FORECAST_HEAT` | 折 | **关** | 前馈是荫，不是水 |
| `LIVE_HEAT` | 折 | 脉冲 PWM | 仅 tank_ok |
| `RECOVER` | 保持再开 | 关 | 温度在降 |
| `INHIBIT_COOL` | 开 | 关 | 带下 |
| `FAULT` | 末姿态 | **关** | 只有琥珀 |

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 泵在假 `LIVE_HEAT` 下脉冲；舵机折 90° | 1+3 |
| 8 | Open-Meteo JSON → NVS `t_max_6h`；无线电没了泵仍关 | 2 |
| 9 | 热箱：热风吹红外探头，叶先折、泵后开（中期检查） | 全组 |

| 11–12 | 可选 AVP 热体积 | 5 |

**第 13 周脚本。** (1) 展示空闲叶。(2) 笔记本：缓存预报 → 叶折，喷嘴干。(3) 热风吹冠层模型 → 2 s 雾、20 s 停。(4) 拔浮子 → 琥珀，雾停。(5) 头显可选。

### Vision Pro
叶子周围的热体积；捏合刷 6 h 预报；注视停留「幼 vs 成」。**不得开火喷雾。**

### 风险
有人提议装进真营地：拒绝。泵漏。DHT 晒高。不声称种群恢复。2026 年 1 月死亡是证据，不是对动物喷水的许可证。

## 2. 灌丛火鸡孵丘窑

### 挑战
澳洲灌丛火鸡（*Alectura lathami*）把丘温「种」在约 **33 °C**。悉尼郊区已有它们；人把丘当「垃圾」耙掉，整窝死。鸟已经有界面。我们加入它。

**文献诚实。** ACI 论述最强；**不是** SoE/KTP 头条。Credit 交互够用；Distinction 要补城市生态文献，或改选从来源出发的构想。

### 非人类利益相关者
- **主 — 卵 / 胚胎。** 稳定孵化带。
- **次 — 雄鸟。** 另一个操作者；通风不能把他逼走。
- **再次 — 拿耙的人。** 可读的「勿耙」旗，不是通知。

### 构想
填覆盖物的 PETG 丘模型 + **仅演示用** 的水族加热棒。

1. `TOO_COOL` — 通风关；可选加热只在模型里。
2. `IN_BAND`（约 32–34 °C）— 通风闲；**旗升起**。
3. `TOO_HOT` — 通风/风扇开。
4. `WEATHER_HOLD` — 气象局冷雨 → 不要大开通风。
5. `PROBE_FAULT` — 旗 **降**（不许假「可以耙」）。
6. `IDLE` — 运输时加热关。

### 一句架构
两只丘心探头 + 空气/雨预报 → ESP32-S3 → 通风/风扇 + 实体旗。温度 **就是** 对话。

```
 世界     丘心 ×2                    空气 / 雨预报
              │                            │
 感知      DS18B20 ×2                   DHT22 + WiFi 气象局
              │                            │
 融合              ESP32-S3  温度带状态机
              │                            │
 执行      MG90S 通风 + 5 V 风扇        MG90S 旗
 演示      沙箱 + 水族加热棒              28 / 33 / 38 °C
```

### 数据流

| 从 | 到 | 信号 | 用途 |
|---|---|---|---|
| DS18B20 A/B | 1-wire | T_core 中值 | 温度带；相差 >2 °C → 故障 |
| DHT22 | GPIO | T_air, RH | 雨/冷保持 |
| 气象局 | NVS | 未来 6 h 雨 | 冷锋前不要把热散光 |
| 状态机 | 舵机 1 | 通风角 | 只在过热时降温 |
| 状态机 | MOSFET | 风扇 | 辅助通风 |
| 状态机 | 舵机 2 | 旗升/降 | 给人的讯息 |

### 硬件栈

外壳：茅草感 PETG、真覆盖物、探头井、旗臂。形态 **就是** 丘。防水 DS18B20 ×2 挂 GPIO 4（同一 1-wire）；DHT22 GPIO 10。**绝不** 把 MCU 埋进真丘。MG90S 通风（GPIO 7）；MG90S 旗（GPIO 11）；5 V 风扇 + MOSFET（GPIO 6）。加热棒走 **独立定时插座**，不要 MCU 控市电。

**BOM 差额。** 2× DS18B20、5 V 风扇、覆盖物、小沙箱、独立回路加热。

### 软件栈

`task_probe` 1 s（两只取中值）· `task_air` · `task_bom` · `task_fsm` · `task_actuate`。

滞后 **±0.5 °C**，通风不抖。探头不一致 → `PROBE_FAULT`。

```
   TOO_COOL（通风关，允许演示加热）
        │  中值 ≥ 32.5
        ▼
   IN_BAND（旗升，通风闲）←→ WEATHER_HOLD（冷锋则通风封顶）
        │  中值 ≥ 34.5
        ▼
   TOO_HOT（通风 + 风扇）
        │  中值 ≤ 33.5
        ▼
   回到 IN_BAND

   探头丢失或 |A−B|>2 ──► PROBE_FAULT（旗降，风扇关）
```

| 状态 | 通风/风扇 | 旗 | 规则 |
|---|---|---|---|
| `TOO_COOL` | 关 | 降 | 不要给冷窝打广告 |
| `IN_BAND` | 闲 | **升** | 「勿耙」 |
| `TOO_HOT` | 开 | 升 | 加入雄鸟的降温，不取代他 |
| `WEATHER_HOLD` | 封顶 | 升 | 预报有雨 |
| `PROBE_FAULT` | 停泊 | **降** | 不许假解除 |
| `IDLE` | 停泊 | 降 | 运输 |

失效 **停泊**。探头死则旗失效 **降**。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 两只舵机：通风 0/45/90，串口升降旗 | 3 |
| 8 | 气象局雨旗限制通风角 | 2 |
| 9 | 加热 28/33/38 °C：只有带内旗升（中期 — 本组最硬实体） | 1+2 |
| 10–11 | 茅草打印，线藏空腔 | 3 |
| 13 | 三温度、三米外可读；「模型，不是巢」 | 4 |

### Vision Pro
丘内 33 °C 等温体积；双手比卵深；注视旗 = 「现在耙会杀死整窝」。

### 风险
报告把加热棒写成「拯救了巢」。写清：模型。第 13 周最不容易翻车的实体。

## 3. 黄昏负鼠猫门

### 挑战
户外猫（宠物与野猫）是澳大利亚兽类和鸟类下降的主要推手之一（Woinarski / Legge；TAP 2024；DCCEEW 每年 15 亿）。帚尾负鼠（*Trichosurus vulpecula*）仍要沿郊区篱笆夜行。同一走廊，相反需求。

### 非人类利益相关者
- **主 — 负鼠。** 黄昏后跑道开。
- **次 — 黎明小鸟。** 门不能变成晨间猫蹲点。
- **猫。** 不是受益者。不用超声波（同样打到野生动物）。

### 构想
夹在 1.2 m 演示篱上的木/PETG「树枝」。

1. `DAY` — 缝锁住（可选，或停泊）。
2. `DUSK_POSSUM` — 照度低于阈；类别负鼠 → 缝 **开**。
3. `DUSK_CAT` — 类别猫 → 缝 **关**。
4. `HUMAN` — 人在栏上 → 绝不夹（开或忽略）。
5. `API_DOWN` → 黄昏后对负鼠体型交通 **失效开放**。
6. `FAULT` → 失效开放 + 维护灯。

### 一句架构
黄昏 × 栏上的身体 × 身份 → ESP32-S3 → 翻板几何。正义 = 图像 API 挂了就失效开放。

```
 世界     黄昏光              栏上的身体              谁（猫/负鼠/人）
              │                    │                       │
 感知      BH1750              LD2410 或 ToF            摄像头 → 图像 API
              │                    │                       │
 融合                    ESP32-S3  正义状态机
              │                    │
 执行              MG90S 翻板 / 缝
 演示       玩偶猫 vs 玩偶负鼠 vs 人
```

### 数据流

| 从 | 到 | 信号 | 用途 |
|---|---|---|---|
| BH1750 | I2C | lux | 黄昏带 vs 白天 |
| LD2410 | UART | 存在、距离 | 1 s 保持；忽略远处杂波 |
| 摄像头 / HTTP | WiFi | class_id, conf | 猫 / 负鼠 / 人 / 空 |
| 限位 | GPIO 12 | gap_clear | **缝里有身体时绝不关** |
| 状态机 | MG90S | 开/关 | 几何做大部分工作 |

### 硬件栈

ESP32-S3-CAM **或** ESP32-S3 + OV2640；BH1750 I2C；LD2410 UART；MG90S；需要时电平转换。图像 API（云）或 Edge Impulse 板端为 stretch。云端：WiFi；挂了则失效开放。

**引脚。** 摄像头板会抢走默认 GPIO — 在 `fsm.h` 写明丝印。即使不用也把 ADC1 留着。舵机用 CAM 板不占用的脚（常仍是 GPIO 7；**要核对**）。

**外壳。** 夹式树枝：缝宽就是设计。CAD 负鼠体型剪影 vs 猫肩宽剪影。几何 > 分类器。

**BOM 差额。** ESP32-S3-CAM（或 OV2640）、玩偶猫 + 玩偶负鼠、1.2 m 木栏、缝内限位。

**不要买。** 超声波「驱猫」。活猫测试。

### 软件栈

`task_lux` · `task_radar` · `task_classify`（HTTP 或本地，2–5 s）· `task_fsm` · `task_servo`。

存在保持 **1 s**。`gap_clear` 为假 → 冻结舵机（夹伤）。置信度 < 0.6 → 黄昏当作 `API_DOWN`。

```
   DAY（缝锁或停泊）
        │ lux < L_DUSK
        ▼
   DUSK_WAIT ── 类别负鼠 / 未知+api_ok==false ──► DUSK_POSSUM（开）
        │
        ├── 类别猫 ──► DUSK_CAT（关）
        ├── 类别人 ──► HUMAN（不夹；缝里有身体则开）
        └── lux > L_DAY ──► DAY

   黄昏后 api_ok false ──► FAIL_OPEN（负鼠体型交通）
   故障 ──► FAIL_OPEN + 琥珀
```

| 状态 | 缝 | 规则 |
|---|---|---|
| `DAY` | 关 | 不当蹲点 |
| `DUSK_POSSUM` | 开 | 受益者 |
| `DUSK_CAT` | 关 | 威胁 |
| `HUMAN` | 冻结/开 | 安全 |
| `FAIL_OPEN` | 开 | 分类器死了；负鼠不能等 WiFi |
| `FAULT` | 开 | 琥珀 |

写清假阳性（对负鼠关上）和假阴性（对猫开着）**谁付出代价**。建议：伦理残差是误开；几何仍挡得住肥猫。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 舵机开/关；限位中止关闭 | 3 |
| 8 | HTTP 分类桩：三张 JPEG（猫/负鼠/人） | 2 |
| 9 | 黄昏照度下玩偶负鼠 → 开；玩偶猫 → 关；拔 WiFi → 开 | 1+2 |
| 10–11 | 打印树枝，夹到栏上 | 3 |
| 13 | 三种身体 + WiFi 掉线；无活体 | 4 |

### Vision Pro
负鼠 vs 猫的眼高；指缝「谁过得去」。注视 **不** 关门。

### 风险
分类错误：写清谁买单。不声称物种恢复。不测活猫。NSW 仍无全州猫宵禁 — 装置是篱笆模型，不是法律。

## 4. 玻璃撞鸟遮帘

### 挑战
黎明时透明玻璃读成天空或栖息地。小型林鸟（银眼、刺嘴、吸蜜鸟）撞击校园与城市玻璃。贴纸没人理；鸟活动的时段建筑仍是致命的。

**文献诚实。** 全球城市问题；校园为真；不是名录 KTP。本组最强 MR 叠加。

### 非人类利益相关者
- **主 — 小型林鸟。** 民用曙暮光和低太阳/雾时，玻璃不能看起来像走廊。
- **次 — 室内的人。** 遮帘不能无理由全天落下。这是 **模型窗**。

### 构想
桌面镜框玻璃（约 600 mm）。

1. `DAY_CLEAR` — 帘起。
2. `TWILIGHT_DOWN` — 照度带 → 帘 **下**（默认保护）。
3. `STRIKE_DOWN` — 毫米波鸟体型、快特征 → 白天也下。
4. `FOG_DOWNSUN` — 天气 API → 当黄昏处理。
5. `HUMAN_OVERRIDE` — 可选 PIR：不要把人关在黑里；写明这是模型。
6. `FAULT_DOWN` — 帘下（对鸟失效安全）。

### 一句架构
黎明照度 + 接近 + 天气 → ESP32-S3 → 有图案遮帘。窗就是 UI。失效 **落下**。

```
 世界     黎明光 / 雾              玻璃前的接近
              │                         │
 感知      BH1750 + 气象局           LD2410（+ 可选摄像头）
              │                         │
 融合                    ESP32-S3
              │                         │
 执行         MG90S 珠帘 / 有图案 PETG 遮帘
 演示            把房间弄暗 + 鸟剪影
```

### 数据流

| 从 | 到 | 信号 | 用途 |
|---|---|---|---|
| BH1750 | I2C | lux | 民用曙暮光带 |
| LD2410 | UART | 存在、速度近似 | 白天撞击 |
| 气象局 | NVS | 雾、低太阳、云 | 额外落下 |
| 可选摄像头 | API | 鸟 vs 非鸟 | Credit；黄昏不依赖它 |
| 状态机 | MG90S（+ 可选第二只） | 帘下/上 | 图案 **就是** 生态 |

### 硬件栈
BH1750、LD2410、MG90S、ESP32-S3、600 mm 框、激光切 / 打印图案（点阵，不必实心遮光 — 若要 Credit 叙事：人能读出「这是给鸟的」）。可选摄像头做鸟 vs 非鸟（第 8 周）。

**BOM 差额。** 亚克力板、按撞鸟文献间距（密图案）打印的帘、竹签上的鸟剪影。

### 软件栈

状态：`UP` `TWILIGHT_DOWN` `STRIKE_DOWN` `FOG_DOWN` `HUMAN_OVERRIDE` `FAULT_DOWN`。

滞后：进黄昏用 L_LOW，出用 L_HIGH（荧光灯房间不抖）。撞击在最后一次快特征后 **保持 15 s**。

失效 **落下**。API 挂了仍用照度；不要失效 *升起*。

| 8 | 天气 JSON 雾 → 下；WiFi 关照度仍工作 | 2 |

不要声称改造了校园楼。桌面是模型。

## 5. 初段径流延迟堰

### 挑战
悉尼暴雨把头几毫米脏水 — 油、泥、狗粪 — 冲进 Cooks、Wolli、Parramatta。短鳍鳗与河岸无脊椎仍用这些系统。生态侮辱是初段，不是雨本身。要从来源出发的版本见 [[from-sources_cn]] 构想 H（CRVA / EPA）。

### 非人类利益相关者
- **主 — 鳗 / 大型无脊椎。** 更晚、更干净的流。
- **次 — 河岸植物。** 不要每场暴雨被淤埋。
- Country/水的文献；**不要把原住民知识当戏服。**

### 构想
砂岩色堰，两个托盘。

**选定默认：** 头 N 毫米一律进蓄水（简单、能演）。

1. `DRY` — 瓣对准蓄水就绪（或停泊关闭）。
2. `FIRST_FLUSH` — 雨起 + 浊度高 → 脏蓄水。
3. `CLEAN_FLOW` — N 毫米之后 **或** 浊度下降 → 溪流托盘。
4. `SETTLE` — 蓄水静置。
5. `PRE_STORM` — 气象局临近预报 → 瓣就绪。
6. `FAULT` — 最后安全位（写明：蓄水）。

### 一句架构
雨 + 水中的脏 + 预报 → ESP32-S3 → 堰瓣。水就是显示器。

```
 世界     雨                  水中的脏                 预报
              │                    │                       │
 感知      翻斗或土壤湿度       模拟浊度                 WiFi 气象局
                               （LED + 光电管）
              │                    │                       │
 融合                    ESP32-S3
 执行              MG90S 堰瓣
 演示       茶+金葱 vs 清水
```

### 数据流

| 从 | 到 | 信号 | 用途 |
|---|---|---|---|
| 翻斗 **或** 土壤湿度模拟 | GPIO 中断或 ADC1 GPIO 1 | rain_mm, raining | 暴雨开始 |
| 通道上的 LED + 光电管 | ADC1 GPIO 2 | 浊度 | 脏 vs 清 |
| 气象局临近 | NVS | 未来 60 min 雨 | 预关闭 |
| 状态机 | MG90S | 蓄水 vs 溪 | 两托盘三米外可读 |

### 硬件栈
雨：翻斗 **或** 模拟土壤湿度作代理。浊度：廉价光学模拟走 **ADC1**（LED 经 MOSFET 吃 5 V，光电管进 ADC，光强取反）。ESP32-S3、MG90S、两个 3D 打印托盘、砂岩 PETG 堰。电子干燥、在溅水上方。

**BOM 差额。** 白光 LED + 光电管、茶 + 金葱、两托盘、可选真翻斗。

**不要。** 接到校园雨水管。染料进下水道。

### 软件栈

状态：`DRY` `FIRST_FLUSH` `CLEAN` `SETTLE` `PRE_STORM` `FAULT`。

演示 N_mm = 3–5 mm 模型（一壶）。浊度阈值用茶 vs 自来水标定。滞后，避免金葱沉降让瓣抖动。

失效：瓣到 **蓄水**（对「溪」保护）。API 挂了：仍跑头 N 毫米，不做临近预报。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 串口：壶 A 倒左、壶 B 倒右 | 3 |
| 8 | 临近预报桩预移动瓣 | 2 |
| 9 | 茶+金葱 → 蓄水；随后自来水 → 溪（中期） | 1+2 |
| 10–11 | 砂岩打印，舵机藏进堰身 | 3 |
| 13 | 两壶三米外；Country 有引用、无戏服 | 4 |

### Vision Pro
脏颗粒只出现在初段体积。刷一场暴雨。注视蓄水 vs 溪。

### 风险
体积很小。不接真雨水管。不能引用的河段不要编名录鳗。

## 6. 噪钟矿鸟致密挡板

### 挑战
噪钟矿鸟（*Manorina melanocephala*）占领许多东澳郊区种植，攻击性排除小型食虫鸟。矿鸟喜欢公园式开阔；鹪莺和刺嘴需要视觉致密。

**文献诚实。** 真实城市鸟生态；不是 2025–26 国家紧急事件。

### 非人类利益相关者
- **主 — 华丽细尾鹩莺 / 东刺嘴。** 视觉致密。
- **矿鸟。** 竞争者，不是噪音武器的靶子。

### 构想
花槽尺度的灌丛。**不对动物用喇叭。**

1. `QUIET` — 叶片打开/停泊。
2. `MINER_CHORUS` — BirdNET 一类识别 → 叶片收成致密。
3. `WIND` — 气象局/风速计 → 不跟大风较劲。
4. `RAIN` — 叶片停泊。
5. `NIGHT` — 停泊。
6. `FAULT` — 停泊（失效到「不把自己搞坏」）。

### 一句架构
矿鸟声 + 风/雨/夜 → ESP32-S3 → 灌木叶片。拒绝喇叭。失效 **停泊**。

```
 世界     矿鸟声                   风 / 雨
              │                         │
 感知      I2S 或模拟麦               照度 + 气象局
              │                         │
 融合         ESP32-S3（+ WiFi 到声音 API）
 执行      MG90S 灌木叶片 ×2–4
 演示         封闭箱 + 耳机进麦
```

### 硬件栈
INMP441 I2S **或** 模拟麦 + MAX9814 走 ADC1（若用 WiFi，记住 ADC2）。ESP32-S3、MG90S ×2–4、激光切木材 + PETG 叶。ADC 与 WiFi 打架：BLE 听节点 + 执行节点（第 6 周实验）。API：BirdNET-Pi HTTP **或** 校园安全的频谱代理。

**引脚改动。** I2S 常占 GPIO 4 WS、5 SCK、6 SD — **然后琥珀改 GPIO 13，泵不用，舵机仍 7/11。** 写进该构想的 `sdkconfig`。

**BOM 差额。** INMP441 或 MAX9814、额外 MG90S、封闭演示箱、耳机。

**不要。** 校园广播回放（会引来真矿鸟）。反矿鸟喇叭。

### 软件栈

`task_audio`（I2S 帧或 ADC 包络）· `task_api`（BirdNET）· `task_lux` · `task_fsm` · `task_actuate`。

第 9 周若只用模拟：矿鸟频带能量 + 峰率当 **代理**，第 8 周 API 再升级标签。报告里把代理写成代理。

失效 **停泊**。风速超阈即使合唱也停泊。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 串口收四片叶 | 3 |
| 8 | 文件上传 / HTTP「矿鸟」vs「风」 | 2 |
| 9 | **箱内** 耳机让叶收；静音停泊 | 1+2 |
| 13 | 花槽三米外读成灌木 | 4 |

### Vision Pro
声场当体积；注视小型鸟的口袋。

### 风险
回放引来真矿鸟 — 不要。鹪莺不欠你一套手势。

## 7. 不是猫碗的吸蜜鸟水盆

### 挑战
热浪水盆是郊区所剩不多的水源之一，也给猫搭了蹲守的桌子。两个澳大利亚议题（热；户外猫）在一只碗里相遇。

### 非人类利益相关者
- **主 — 白颊吸蜜鸟 / 小垂蜜鸟。** 热时要凉而浅的水。
- **猫。** 不是受益者。不测活猫。

### 构想
石感碗、细底座（难蹲）。

1. `OPEN_HEAT` — 水温可、白天、无猫 → 开。
2. `RECIRC` — 水烫 → 泵 / 遮荫。
3. `LID_CAT` — 毫米波猫体型在沿 + 黄昏 → **盖 / 抬升**。
4. `BIRD_HOLD` — 图像是鸟 → 保持开。
5. `LID_NIGHT` — 盖上（蚊 + 猫）。
6. `EMPTY` / `FAULT` — 维护：人工倒掉；泵关。

报告写 **两张** ESD 表（鸟喝 vs 猫猎）。

### 一句架构
水温 × 黄昏 × 沿上是谁 → ESP32-S3 → 盖 + 循环。盖是为鸟投的有形一票。

```
 世界     水温              黄昏           沿上是谁
              │                │                 │
 感知      DS18B20          BH1750         毫米波 + 图像 API
 融合                    ESP32-S3
 执行      5 V 泵            MG90S 盖
 演示       热水 vs 凉水；玩偶猫在沿上
```

### 硬件栈
DS18B20 放 **测温井**（不是活体自来水管网）。BH1750、沿高 LD2410、可选摄像头、泵、MG90S 盖、ESP32-S3。电子在底座里，近似防水垫圈，绝不进碗。

**BOM 差额。** 石感打印、泵、玩偶猫、浅盘（每晚倒空）。

### 软件栈

状态：`OPEN_HEAT` `RECIRC` `LID_CAT` `LID_NIGHT` `BIRD_HOLD` `FAULT`。

碗里检测到身体时盖不得关上（夹）。夜间默认盖。气象局热浪可在 10:00 前 **预注** 模型（泵进碗）— 罐空则失效 **关断**。

冲突的 Desired：鸟 **和** 猫特征同时出现 → **盖**（不给猫搭桌子）。写明鸟会失去那一分钟；细底座几何是其余的防御。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 盖 + 泵 PWM | 3 |
| 8 | 图像桩猫 vs 鸟；气象局热预注 | 2 |
| 9 | 热水 → 循环；黄昏玩偶猫 → 盖 | 1+2 |
| 13 | 手册里倒空清洗（蚊） | 4 |

### Vision Pro
猫锥 vs 鸟锥。注视 = 水的伪彩。

### 风险
蚊：倒空清洗。不测活猫。积水伦理写进报告。

## 8. 港湾泥沙阀（岩蚝架）

### 挑战
雨后悉尼港有淡水/泥沙脉冲。悉尼岩蚝（*Saccostrea glomerata*）在这窗口里摄食差。养殖与野生床同一侮辱。

### 非人类利益相关者
- **主 — 蚝。** 摄食窗口少泥。
- **次 — 海草（光气候）。** 论文里提；不要把水缸说成河口。若要 2026 *Posidonia* 故事，见从来源构想 E — 不要做两个水缸项目。

### 构想
10 L 缸、微型木架。**电子绝不进盐水** — 淡水 + 泥沙模型。

1. `CLEAR` — 瓣开 / 气泡关。
2. `SILT` — 浊度升 → 关闭架的模型。
3. `PRE_STORM` — 气象局 → 预关。
4. `REOPEN` — 浊度降 → 开。
5. `TEMP` — 可选温度冲击。
6. `FAULT` — 架关。

### 一句架构
泥水 + 雨预报 → ESP32-S3 → 瓣（和/或气）。在已经普适的系统（港湾）里加一只安静的阀。失效 **关闭**（保护）。

```
 世界     泥水                     雨预报
              │                         │
 感知      模拟浊度 + DS18B20         WiFi 气象局
 融合                    ESP32-S3
 执行      MG90S 瓣  和/或  气泵
 演示       倒泥水；阀关
```

### 硬件栈
光学浊度走 ADC1，DS18B20 在干井或密封套管，ESP32-S3、MG90S、可选 5 V 气泵、木+PETG 架。3.3 V 与湿侧隔离。缸放托盘上。

**BOM 差额。** 10 L 缸、栽培泥 / 膨润土、木架。**不要盐。**

### 软件栈

状态：`CLEAR` `SILT` `PRE_STORM` `REOPEN` `TEMP` `FAULT`。

浊度下降后 `SILT` 再保持 30 s（滞后）。API 挂了：仍按浊度关；跳过预关。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 串口关瓣；电子保持干燥 | 3 |
| 8 | 气象局雨 → 预关 | 2 |
| 9 | 倒泥 → 关；冲清 → 开（三米外可读） | 1+2 |
| 13 | 「不是港口部署」 | 4 |

### Vision Pro
泥沙体积注册到架上。MR 显示滤什么；电机做模拟。

### 风险
盐杀电路板。不部署港口。小缸 ≠ 河口。

## 9. 铃蛙水文周期泵

### 挑战
绿金铃蛙（*Litoria aurea*，濒危）需要有 **水文周期** 的塘：湿得够久才能变态，又不是永蓄的鱼/蚊泥潭，也不是冲走卵的洪水。悉尼奥林匹克公园是著名地点。**演示：** 条纹泽蛙 / 东澳大利亚蛙鸣 + 托盘；利益相关者仍点名 *L. aurea*，并写明模型不是名录种的塘。

### 非人类利益相关者
- **主 — 被点名物种的蝌蚪。** 水文周期。
- **次 — 成体。** 雨后鸣叫栖息，泵不能淹死卵筏。

### 构想
15 L 托盘边的陶/PETG「石头」。产品是水文周期，不是喷泉。

1. `DRY` — 土干、无雨 → **不注水**。
2. `FILL` — 雨 + 预报随后干热 → 注到蝌蚪深度。
3. `HOLD` — 把带维持 N 天（演示：N 分钟）。
4. `REFUSE_FLOOD` — 太满 → 拒绝泵；可略排。
5. `RECIRC` — 可选微循环，**不是鱼**。
6. `FAULT_OFF` — 泵关。

### 一句架构
雨 + 水位 + 预报 → ESP32-S3 → 可以 **拒绝** 的泵。失效 **关断**。

```
 世界     雨 / 土               水深                  蛙鸣（可选）
              │                      │                      │
 感知      湿度或翻斗            超声波/ToF 水位         模拟麦
 FUSE                    ESP32-S3 + 气象局
 执行      5 V 泵 + MOSFET      可选排水舵机
 演示       倒「雨」；展示拒绝超填
```

### 硬件栈
模拟土壤湿度 **或** 翻斗；水位用 **ToF**（报告里拿 HC-SR04 声学对「蛙」开玩笑很糟 — VL53L0X / 防水 ToF 更好）；DHT22；ESP32-S3；泵；可选 I2S 麦 + 蛙 API 作 Credit。溢流缺口是机械的（正义写在塑料里）。

**引脚。** ToF 的 I2C 与照度共用 8/9 — 用开关芯片或不用照度。水位走 I2C；湿度走 ADC1 GPIO 1。

**BOM 差额。** 15 L 托盘、泵、ToF、土壤湿度探头、溢流嘴。

### 软件栈

状态：`DRY` `FILL` `HOLD` `REFUSE_FLOOD` `RECIRC` `FAULT_OFF`。

水位带例如模型 40–60 mm。水位 > 70 mm **或** 雨超过 N 则 `REFUSE_FLOOD`。气象局雨后热 → 允许 `FILL`；整周雨 → 拒绝（冲刷模型）。

可选麦 **不是** 蝌蚪检测器；是 Credit 情境（「雨后成体在叫」）。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 泵注到刻度 **停止**；固件死了溢流缺口仍工作 | 1+3 |
| 8 | 气象局：雨后干热允许注；长雨拒绝 | 2 |
| 9 | 倒雨 → 注；继续倒 → 拒绝（中期） | 全组 |
| 13 | 诚实幻灯：*L. aurea* vs 泽蛙模型；无活蝌蚪 | 4 |

### Vision Pro
托盘里随时间变化的水体幽灵（快照看不见的水文周期）。

### 风险
动物伦理：不需要活蝌蚪。染料不进校园下水道。*L. aurea* vs 演示蛙要诚实。

## 10. 袋狸黎明涵洞

### 挑战
长鼻袋狸（*Perameles nasuta*）仍在悉尼残林边缘（Centennial Park、North Head 等）存活。篱笆、猫、狐、黎明行人切断 **地面** 跑道。这不是篱顶负鼠问题：是嗅探高度的隧道。

### 非人类利益相关者
- **主 — 袋狸。** 黎明/黄昏黑暗、排猫的爬行。
- **次 — 猫/狐。** 用几何 + 盖排除，不用超声波。

### 构想
演示板上的木/PETG 篱下隧道。

1. `DAY_SHUT` — 可选关闭。
2. `DUSK_OPEN` — 照度在黎明/黄昏带、无猫体型 → 隧道开。
3. `CAT_SHUT` — 图像/毫米波猫 → 瓣 **关**。
4. `PREY_OPEN` — 低、长体型类别 → 开。
5. `FAIL_DUSK_OPEN` — API 挂：黄昏照度 **失效开放**，大白天关。
6. `FAULT` — 维护灯。

### 一句架构
