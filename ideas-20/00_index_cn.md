## 怎么读

**生态挑战** = 一句话说清澳大利亚情境（Distinction 要求后面用文献撑住，不要只喊口号）。

**交互设计亮点** = 课程里的交互概念（W2 ESD / 隐式 / 近身学 / 状态机；W5–9 有形外壳；W6–7 手势 vs 电机；W8 API；W10–12 可穿戴 / 注视 / 混合现实）。不是传感器清单。

Pass 产品始终是：单片机 + ≥2 类传感器 + 非屏幕驱动 + 自制外壳。头显只用于探询。

## 1–8（第一轮短名单）

### 1. 营地边缘热浪庇护
**挑战。** 悉尼灰头狐蝠营地在热浪中，当气温与栖位微气候越过文献中的热应激阈值时会大量死亡，幼蝠尤其如此。
**交互亮点。** *前馈，不是事后补救：* 遮荫/喷雾由预报（W8）在喘气开始前触发。默认 **关**。吊挂的叶子就是界面（W9）。注视/MR 显示看不见的热，但不得开泵。

### 2. 灌丛火鸡孵丘窑
**挑战。** 郊区灌丛火鸡已经在为卵「种」丘温（约 33 °C）；人把丘耙掉，整窝塌掉。
**交互亮点。** *加入动物已有的界面*（ACI）：温度 **就是** 对话，不是按钮。实体「勿耙」旗是给人类的有形讯息。隐式交互论述最强。

### 3. 黄昏负鼠猫门
**挑战。** 户外猫是澳大利亚物种灭绝的主要推手之一，而帚尾负鼠仍要在同一庭院沿篱笆夜行。
**交互亮点。** *近身学做成几何：* 身份 × 黄昏 × 体型决定缝宽。图像 API 挂了则 **对负鼠失效开放** — 正义写在状态机里，不是口号。

### 4. 玻璃撞鸟遮帘
**挑战。** 黎明时校园与城市玻璃呈现「可以飞穿」的错觉，撞死小型林鸟。
**交互亮点。** *窗就是 UI*（安静的 ubicomp）。民用曙暮光默认遮帘 **放下**。本组最强混合现实叠加（鸟看玻璃 vs 人看玻璃），但不把 MR 当产品。

### 5. 初段径流延迟堰
**挑战。** 悉尼暴雨头几分钟把油、泥、粪冲进仍有鳗鲡与河岸生命的溪流。
**交互亮点。** *水就是显示器：* 两个托盘让初段脏流 vs 净流不靠屏幕也能读懂。Country/水的论述不当戏服。W2 状态机很干净（干 / 脏 / 净 / 沉）。

### 6. 噪钟矿鸟致密挡板
**挑战。** 噪钟矿鸟占领东海岸开阔种植，把需要视觉致密、而不是更多噪音的小型食虫鸟挤走。
**交互亮点。** *拒绝喇叭。* 致密叶片才是媒介。隐式音频情境（W2，W8 BirdNET）。把手势课反过来用：鹩莺不欠你一套手势。

### 7. 不是猫碗的吸蜜鸟水盆
**挑战。** 热浪饮水器帮了吸蜜鸟，同时给户外猫搭了蹲守的桌子。
**交互亮点。** *两个 Desired 互相冲突* — ESD 写两遍。盖子是为鸟投的有形一票。热（模拟量）与捕食者（存在/图像）收在同一物件里。

### 8. 港湾泥沙阀（岩蚝架）
**挑战。** 降雨脉冲把泥沙和淡水打进悉尼港，压缩悉尼岩蚝的摄食窗口。
**交互亮点。** *在已经普适的系统里加一只安静的阀*（港湾本身）。水缸三米外能读懂。MR 显示「滤什么」；电机做模拟。

## 9–20（扩到二十）

### 9. 铃蛙水文周期泵
**挑战。** 绿金铃蛙需要一个够湿、够久才能变态的临时塘；若塘永远蓄满，则变成鱼、蚊和冲刷，蝌蚪反而死。
**交互亮点。** *产品是水文周期，不是喷泉。* 雨 + 水位决定泵可以 **拒绝注水**。演示可用常见泽蛙；报告里点名的利益相关者仍是 *Litoria aurea*，并写明这种诚实。

### 10. 袋狸黎明涵洞
**挑战。** 长鼻袋狸仍在残林边缘觅食，但篱笆、猫和黎明人流切断了地面跑道。
**交互亮点。** *地面近身学*（不是篱笆顶上的负鼠把戏）。袋狸钻得过、猫钻不过的爬行几何。黎明时钟是模式开关。

### 11. 友蝠果网松弛
**挑战。** 后院果网在网目和张力不对时，会把灰头狐蝠缠死在树上。
**交互亮点。** *张力就是界面。* 网里出现狐蝠体型时 **失效松弛（fail-slack）**。与安防系统相反。把 WIRES/DCCEEW「野生动物友好网」做成机械。

### 12. 无刺蜂巢门
**挑战。** 澳洲无刺蜂（*Tetragonula*）巢会过热、会进雨，采集蜂仍需要在合适温度开门。
**交互亮点。** *昆虫 ACI：* 巢体就是外壳。门要有滞后（不要抖开抖关）。热 + 雨是隐式输入。不要做「养蜂人 App」。

### 13. 乡土幼苗旱滴
**挑战。** 热和干土杀死新种的悉尼林地管苗，而定时灌溉要么淹根，要么错过热浪。
**交互亮点。** *植物才是用户。* 土壤湿度是被感知的身体；BoM 热浪是前馈。滴灌可以 **一直关**。外壳像浇水石，不像小电器。

### 14. 疫霉洗靴闸
**挑战。** 步行者把疫霉等土传病原带进残林，杀死无法走开的山龙眼科等植物。
**交互亮点。** *人是传播媒介；闸是仪式。* 与 Country 的有形同意：洗靴水说靴子干净了，路才开。植物/Country 论述最强。AVP 注视可显示「你会带上什么」，但不许开锁。

### 15. 蓝舌蜥饵盖
**挑战。** 四聚乙醛蜗牛药是生态陷阱：东部蓝舌石龙子吃中毒蜗牛（有时直接吃颗粒）会死亡。
**交互亮点。** *非人类一到，就把陷阱盖上。* 蜥蜴体型签名 vs 只容蜗牛的孔径。郊区、好演示、伦理锋利。

### 16. 小企鹅黄昏岸门
**挑战。** 小企鹅黄昏上岸（Manly / 北港）时，同一片沙上的狗和狐会把它们冲散或咬死。
**交互亮点。** *摇摆步态 vs 犬步。* 读身体 + 黄昏，**对狗失效关闭、对企鹅体型低轮廓开放**。绝不用活体；玩偶 + 步态回放。全国知名议题，校园可演。

### 17. 蜜袋鼯夜间穿越
**挑战。** 郊区树冠破碎后，蜜袋鼯只在夜、风小的时候才肯过空隙。
**交互亮点。** *风就是模式。* 杆/索 **只在夜间且风安全时伸出去** — 否则那是假邀请。有形基础设施，不给鼯戴追踪器。

### 18. 水龙晒岩
**挑战。** 校园砂岩上的东部水龙被人惊下石头后，一时无法回温。
**交互亮点。** *不要惊吓。* 对人用近身学慢屏；石头上有龙体型时电机不得猛动。热舒适是给非人类的输出；人得到的是安静屏障，不是警报。

### 19. 䴢高潮栖绳
**挑战。** 鹊䴢等滨鸟在悉尼/Botany  shrinking 的高潮栖地被未牵绳的狗赶飞。
**交互亮点。** *潮汐钟 + 狗的存在。* 高潮时绳子作为环境建筑展开。不是警报器。潮汐是本组最漂亮的 W2 隐式输入。

### 20. 针鼹停割桩
**挑战。** 短吻针鼹白天在草坪和残林边觅食，在这个时间窗被割草机伤害，土壤也被压实。
**交互亮点。** *旗是给操作者看的，不是给动物穿的。* 振动 + 时钟 + 土壤。桩是 W9 有形物，并把 W10「可穿戴」逻辑反过来（该注意的是推割草机的人）。
