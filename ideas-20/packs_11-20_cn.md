## 11. 友蝠果网松弛

### 挑战
后院果网在网目和张力不对时，会把灰头狐蝠缠死在树上。WIRES / DCCEEW「野生动物友好网」已是政策语言：白色、绷到不兜袋、**不是** 40 mm 死亡网。我们把 **张力** 做成机械：网里出现狐蝠体型时 **失效松弛**。与安防系统相反。

### 非人类利益相关者
- **主 — 灰头狐蝠（及其他果蝠）。** 网要松并把它们放下去，而不是越缠越紧。
- **次 — 同一张网里的鸟。** 同样松弛。
- **人的水果。** 不是张力的受益者。

### 构想
1 m 演示框、白色针织网、弹簧卷轴 + MG90S 棘爪。

1. `TAUT_OK` — 载荷在水果重量带；棘爪咬住。
2. `BODY_IN_NET` — 载荷尖峰 + 可选红外对射 → 棘爪 **释放**，网松。
3. `NIGHT_SENSITIVE` — 夜间照度：降低载荷阈（蝠）。
4. `WIND` — 风速计/气象局：忽略短阵风（滞后）。
5. `RESET` — 人摇回；限位说又绷上了。
6. `FAULT` — 失效 **松弛**（棘爪打开）。维护琥珀。

### 一句架构
张力 + 夜 +（可选）体型 → ESP32-S3 → 释放棘爪。失效松弛。不是警报。

```
 世界     网载荷 / 身体            夜间照度             风
              │                        │                    │
 感知      称重或模拟应变             BH1750              气象局 / 开关
           （HX711）                  红外对射
 融合                    ESP32-S3
 执行      MG90S 棘爪  （弹簧做松弛）
 演示       沙袋「蝠」丢进网
```

### 数据流

| 从 | 到 | 信号 | 用途 |
|---|---|---|---|
| HX711 + 1 kg 传感器 **或** 模拟 FSR | HX711 GPIO 4/10 或 ADC1 | load_g | 水果 vs 身体 |
| BH1750 | I2C | lux | 夜 = 蝠时 |
| 跨兜袋的红外对射 | GPIO 12 | beam_broke | 确认是身体，不是风 |
| 气象局风 | NVS | 阵风 | 忽略 <2 s 尖峰 |
| 状态机 | MG90S | 棘爪咬合/释放 | 弹簧把网放松 |
| 人摇 | 限位 | taut_ok | 复位 |

### 硬件栈

木框 1×1 m、白色针织 **野生动物友好** 网（引用网目）、卷轴 + 扭簧。网 **就是** 界面。HX711 + 称重（优先）或 ADC1 上的 FSR；BH1750；红外门。HX711 不是 ADC2；时钟/数据走 GPIO 4/10。MG90S **只当棘爪** — 能量存在弹簧里。不要让 2.5 kg 舵机去接住一只蝠。

**引脚。** HX711 DT/SCK 在 GPIO 4/10。舵机 GPIO 7。红外 GPIO 12。无泵。

**BOM 差额。** HX711、称重传感器、白色网（正确网目）、扭簧、沙袋。**不要** 买 40 mm 六角「防鸟网」 — 那就是问题本身。

演示：300–500 g 带蝠剪影的沙袋。绝不用活体。

### 软件栈

`task_load` 20 ms · `task_lux` · `task_beam` · `task_api`（风）· `task_fsm` · `task_actuate`。

载荷：200 ms 中值。夜间阈值低于白天（偷果 vs 蝠）。风：要求载荷 **且** 对射，或载荷保持 >1.5 s。

```
   TAUT_OK
      │ 夜 AND（载荷 > L_BAT 或对射）
      │ 昼 AND（载荷 > L_BODY 且对射）   // 忽略水果碰一下
      ▼
   BODY_IN_NET（棘爪释放，网松）── 人复位 ──► TAUT_OK
      │
   WIND_HOLD（阵风，无对射）── 回到 TAUT_OK
   故障或掉电 ──► FAIL_SLACK
```

失效 **松弛**。和你写过的每个防盗警报相反。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 棘爪释放；MCU 没电弹簧仍能松网（机械失效松弛） | 3 |
| 8 | 气象局风忽略 <1 s 猛拉 | 2 |
| 9 | 「夜」照度沙袋 → 松；苹果重量碰撞不触发 | 1+2 |
| 13 | 引用 WIRES/DCCEEW 网目；把 40 mm 当反面教材 | 4 |

### Vision Pro
网中的缠绕体积；注视「这种网目会卡住拇指」。头显不触发棘爪。

### 风险
活蝠：永不。弹簧能量：说明书写清对手指。不声称认证了后院网。

## 12. 无刺蜂巢门

### 挑战
澳洲无刺蜂（*Tetragonula*）巢会过热、会进雨，采集蜂仍需要在合适温度开门。昆虫 ACI：巢体就是外壳。不要做「养蜂人 App」。

**文献诚实。** 除非引用本地蜂农 / *Tetragonula carbonaria* 热学论文，否则是从实验室往外设计。演示用 **空** 巢模型，或经同意的观察箱 — 不是野巢。

### 非人类利益相关者
- **主 — 采集蜂。** 采集带开门，雨/热峰关门。
- **次 — 子脾。** 热惯性；门要有滞后，不要抖开抖关。
- **养蜂人。** 只有琥珀灯；无手机。

### 构想
按澳洲 *Tetragonula* 箱比例打印的巢箱模型。

1. `FORAGE_OPEN` — T 在带内、干、白天 → 门开。
2. `HEAT_SHUT` — 巢温高 → 门趋于关（通风策略：**小** 上通风仍在，入口减小 — 引用，不要发明）。
3. `RAIN_SHUT` — 雨感器 → 入口关。
4. `COLD_SHUT` — 夜/冷。
5. `HYSTERESIS` — 任何动作前 2 °C / 5 min。
6. `FAULT` — 失效 **停泊** 末姿态；琥珀。**不要** 把你不拥有的活巢封死。

### 一句架构
巢温 + 雨 + 钟 → ESP32-S3 → 带滞后的入口滑门。箱子就是 UI。

```
 世界     巢气 / 子脾模型           雨            昼
              │                        │              │
 感知      DS18B20 ×2                  雨滴         BH1750
 融合                    ESP32-S3
 执行      MG90S 入口滑块              可选上通风
 演示       热风枪 + 喷壶；不需要活群
```

### 硬件栈
DS18B20 ×2（盖 / 入口），可选 DHT22，雨模拟（叶湿或廉价滴传感器走 ADC1），BH1750，ESP32-S3，MG90S 滑块，按巢箱比例的 PETG 盒，蜂蜡色材料语言。

**不要** 把电子放进蜜里。只要探头井。

**BOM 差额。** 假巢箱、雨感器、第二只 DS18B20。不要摄像头（采集蜂不是分类器演示）。

### 软件栈

`task_probe` 2 s · `task_rain` 200 ms · `task_lux` · `task_fsm` · `task_actuate`。

**滞后就是产品。** 门动作最短间隔 5 分钟。状态：`OPEN` `HEAT_REDUCE` `RAIN_SHUT` `NIGHT_SHUT` `FAULT_PARK`。

API 可选：气象局最高温 → 下午热峰前预减入口（与构想 1 同一套前馈语法）。失效 **停泊**。若真用观察箱，探头死了应在采集时段失效 **开放** — 写清楚；空箱可以失效关。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 滑块开/关；固件 5 min 锁 | 2+3 |
| 8 | 气象局最高温预减 | 2 |
| 9 | 热风 → 减；喷水 → 关；等 5 min（中期） | 1 |
| 13 | 空箱；「没有养蜂 App」 | 4 |

### Vision Pro
箱内热体积；注视入口作为昆虫 ACI。注视不移动门。

### 风险
活无刺蜂：伦理 + 蜂农。卡住的舵机不要封死真群。第 13 周诚实路径是空箱。

## 13. 乡土幼苗旱滴

### 挑战
热和干土杀死新种的悉尼林地管苗，而定时灌溉要么淹根，要么错过热浪。植物才是用户。土壤湿度是被感知的身体；气象局热是前馈。滴灌可以 **一直关**。外壳像浇水石，不像小电器。

### 非人类利益相关者
- **主 — 幼苗（悉尼林地模型：*Themeda*、*Lomandra*，或点名的本地管苗）。** 根区在干 **且** 热将至时需要水；不要沼泽。
- **次 — 残林土壤生物。** 不要过浇。

### 构想
花盆边的石感滴水块。

1. `OFF` — 默认。湿度可或夜凉。
2. `FEEDFORWARD` — 气象局热浪 + 土在干 → **萎蔫前** 滴。
3. `DRY_LIVE` — 白天热、土低于阈 → 短 PWM 滴。
4. `WET_REFUSE` — 土湿 → 拒绝（与构想 9 同一正义）。
5. `EMPTY` — 罐空 → 琥珀，关。
6. `FAULT_OFF`。

### 一句架构
土壤湿度 + 预报热 → ESP32-S3 → 滴灌 MOSFET。失效 **关断**。植物是用户。

```
 世界     根区湿度                  热预报 / 空气
              │                            │
 感知      模拟土壤探头                 DHT22 + WiFi 气象局
 融合                    ESP32-S3
 执行      5 V 滴 + MOSFET             石外壳
 演示       干盆 vs 湿盆；热风当「热浪」
```

### 硬件栈
电容式土壤湿度走 **ADC1 GPIO 1**（能不用就不用会锈的电阻叉），DHT22 GPIO 4，ESP32-S3，5 V 泵或重力电磁阀，0.5 L 罐，PETG 浇水石，管到盆。

**BOM 差额。** 电容土壤传感器、盆 + **自己买的** 林地管苗、水罐。可选第二探头做滞后。

### 软件栈

`task_soil` 2 s（中值，能温度补偿更好）· `task_air` · `task_forecast` 10 min · `task_fsm` · `task_actuate`。

标定 **这一盆** 土 — 原始 ADC 不是「含水率」。视频里两盆：湿的拒绝 vs 干的滴。

状态：`OFF` `FEEDFORWARD` `DRY_LIVE` `WET_REFUSE` `EMPTY` `FAULT_OFF`。

演示延时摄影：滴 10 s / 停 15 min。API 挂了：只跑 `DRY_LIVE`，绝不编热浪。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 串口泵 10 s 再关 | 3 |
| 8 | 气象局热 + 干土 → 滴；湿土拒绝 | 2 |
| 9 | 两盆并排（中期） | 1+4 |
| 13 | 石头读成景观不是电器；ESD 里植物是用户 | 4 |

### Vision Pro
盆内根区湿度体积。注视不开泵。

### 风险
夸大恢复。一盆不是 Cumberland Plain 的拯救。空罐。不要浇别人的残林。

## 14. 疫霉洗靴闸

### 挑战
步行者把疫霉 *Phytophthora cinnamomi* 等土传病原带进残林，杀死无法走开的山龙眼科植物。联邦 *Arrive Clean, Leave Clean* 才是真正的干预。人是传播媒介；闸是 **仪式**。20 条里最强的植物/Country 论述。报告只选 **一种** 病原（疫霉 **或** 壶菌，不要两套小电器）。

### 非人类利益相关者
- **主 — 山龙眼科 / 砂岩林地（瓦勒迈杉在 110 名里 — 当名录语境点名，演示用常见模型）。** 需要脏靴子进不去。
- **Country。** 有形同意；不要戏服。

### 构想
PETG 洗靴池 + 演示栈道板上的转闸。

1. `WAIT` — 路闩上。
2. `WASH` — 靴在池里；浊度/电导说土下来了。
3. `CLEAN_OPEN` — 闩开 N 秒。
4. `STORM_OVERRIDE` — 气象局大雨：写明的人绕行（不要把人冻在暴雨里）。
5. `SKIP` — 有人绕过，可选对射：仍是 **仪式**，不是监狱。
6. `FAULT` — 演示栈道建议失效 **关闭**。若叙事是真防火道伦理：失效开放 +「护林员」— **选一个并论证**。

### 一句架构
洗靴水的脏 +（可选）白昼照度 → ESP32-S3 → 闩。水说靴子干净了，路才开。注视永不解锁。

```
 世界     靴土入水                  行人存在            雨
              │                             │                  │
 感知      模拟浊度 / TDS               LD2410 或垫       气象局
 融合                    ESP32-S3
 执行      MG90S 转闸 / 闩
 演示       脏靴 vs 冲洗过的靴（自己的鞋）
```

### 硬件栈
ESP32-S3，ADC1 上的模拟浊度 **或** TDS，BH1750（白天用），LD2410 或压力垫，MG90S 闩，PETG 洗靴池，篦子，可控的脏土托盘（栽培土）。气象局雨覆盖。

**BOM 差额。** TDS 或浊度对、洗靴盆、闩五金、一双 **牺牲** 靴。

### 软件栈

状态：`WAIT` `WASHING` `CLEAN_OPEN` `STORM_BYPASS` `FAULT`。

洗完：浊度 **先升后降**（土下来了，水又清了）**或** 定时刷 + TDS 变化。廉价版：限位「靴在池里」+ 10 s + 浊度低于 T_clean。

演示失效 **关闭**。API 挂了：仍洗完才开；跳过暴雨绕行。

**AVP 可显示「你会带上什么」— 不得开锁。**

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 只有 GPIO「洗完」桩才开闩 | 3 |
| 8 | 气象局暴雨 → 写明的绕行灯 + 闩开 | 2 |
| 9 | 脏靴失败；冲净靴打开（中期） | 1+4 |
| 13 | 植物/Country 论文；*Arrive Clean, Leave Clean*；不要监狱美学 | 4 |

### Vision Pro
靴底幽灵土。注视不开锁。

### 风险
不要在真步道上困人。只做演示板。不要戏服 Country。一个 KTP，一种病原。

## 15. 蓝舌蜥饵盖

### 挑战
四聚乙醛蜗牛药是生态陷阱：东部蓝舌石龙子吃中毒蜗牛（有时直接吃颗粒）会死亡。非人类 **受益者** 一到，就把陷阱盖上。蜥蜴体型签名 vs 只容蜗牛的孔径。郊区、好演示、伦理锋利。

**演示不要用真四聚乙醛。** 惰性颗粒 / 打印圆片。伦理就是点。

### 非人类利益相关者
- **主 — 东部蓝舌石龙子（*Tiliqua scincoides*）。** 药要够不着。
- **蜗牛。** 园丁叙事里的害虫；我们不用盖「保护」它 — 「园艺模式」下孔径只容蜗牛。
- **园丁。** 仍要能药蜗牛，而不把装置做成石龙子喂食器。

### 构想
石感饵站。

1. `SNAIL_APERTURE` — 默认：蜗牛孔径，盖落下。
2. `SKINK_PRESENT` — 毫米波 / ToF 石龙子体型 + 可选图像 → 盖 **锁得更死** / 内托盘收回。
3. `NIGHT_MOLLUSC` — 蜗牛多在夜间：无石龙子则夜开孔径。
4. `DAY_SKINK` — 蓝舌白天活动：白天额外锁。
5. `HUMAN_SERVICE` — 园丁钥匙 / 磁铁（显式、罕见）。
6. `FAULT` — 失效 **关闭**（盖上）。

### 一句架构
体型 × 钟 → ESP32-S3 → 盖 / 托盘。非人类一到，陷阱关上。失效关闭。

```
 世界     蜥蜴体型身体            钟 / 照度           蜗牛时段
              │                        │                    │
 感知      LD2410 + ToF              BH1750               （同一）
           可选摄像头
 融合                    ESP32-S3
 执行      MG90S 盖 / 内托盘
 演示       玩偶/打印石龙子 vs 蜗牛模型；惰性颗粒
```

### 硬件栈
BH1750、LD2410、可选 VL53L0X 测低轮廓、可选摄像头、MG90S、PETG 站（**量过** 的蜗牛孔 vs 石龙子头宽）、惰性颗粒。

**BOM 差额。** 打印 *Tiliqua* 模型、蜗牛模型、饵站外壳。**无毒药。**

### 软件栈

状态：`SNAIL_NIGHT` `DAY_LOCK` `SKINK_SHUT` `SERVICE` `FAULT_CLOSED`。

白天 → 锁（石龙子）。夜 + 无大身体 → 蜗牛孔径。任何时候大身体 → 关。图像 API：石龙子 vs 猫 vs 空 — 猫不是开盖的理由。

失效 **关闭**。API 挂了：保持白天锁 / 关，不要开成自助餐。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 盖开/关；CAD 里孔已量尺寸 | 3 |
| 8 | 可选图像：石龙子模型 vs 空 | 2 |
| 9 | 昼：关；夜 + 无身体：孔径；玩偶石龙子：关 | 1+2 |
| 13 | 「校园无四聚乙醛」；两张 ESD（控蜗牛 vs 石龙子） | 4 |

### Vision Pro
石龙子身体 vs 颗粒。注视不开托盘。

### 风险
毒药。活蜥蜴。不要教人更好地药野生动物。只做惰性演示。

## 16. 小企鹅黄昏岸门

### 挑战
小企鹅黄昏上岸（Manly / 北港）时，同一片沙上的狗和狐会把它们冲散或咬死。摇摆步态 vs 犬步。门读身体 + 黄昏，**对狗失效关闭、对企鹅体型低轮廓开放**。绝不用活体；玩偶 + 步态回放。全国知名议题，校园可演。

### 非人类利益相关者
- **主 — 小企鹅（*Eudyptula novaehollandiae*）。** 黄昏需要低、开的摇摆缝。
- **狗 / 狐。** 关。不用超声波。

### 构想
沙色矮篱模型，宽约 0.8 m。

1. `DAY_SHUT` — 沙滩模型上的人/狗。
2. `DUSK_PENGUIN` — 黄昏照度 + 低轮廓 + 慢步态 → 缝开。
3. `DOG_SHUT` — 高 / 快步态 → 关。
4. `HUMAN` — 绝不夹。
5. `FAIL` — **对狗体型关，对企鹅几何开**。分类器死了：靠 **几何**（企鹅过得去、狗过不去）+ 黄昏钟。写清：几何是正义；ML 可选。

### 一句架构

```
 世界     黄昏                高度 / 步态               类别
              │                      │                      │
 感知      BH1750               LD2410 + ToF             可选摄像头 / IMU 回放
 融合                    ESP32-S3
 执行      MG90S 矮瓣  +  固定企鹅缝
 演示       企鹅玩偶 + 狗玩偶；手机视频步态进麦/IMU
```

### 硬件栈
与 3、10 同一族，**第三种外壳**。固定缝按企鹅尺寸；舵机瓣只管 **狗** 那个开口。BH1750、LD2410、ToF 高度、可选摄像头、ESP32-S3、MG90S。

**步态演示：** 第 9 周不必板端 ML。用毫米波前两种速度移动模型（距离导数当速度）演「摇摆」vs「小跑」。第 8 周图像 API 是 Credit。

**BOM 差额。** 企鹅毛绒/打印、狗毛绒、沙色 PETG、两个开口（黄昏低缝一直开；高门被驱动）。

### 软件栈

状态：`DAY_SHUT` `DUSK_SLOT` `DOG_SHUT` `HUMAN_SAFE` `API_DOWN_GEOM` `FAULT`。

`API_DOWN_GEOM`：黄昏 → 企鹅缝物理上仍开；高瓣保持 **关**。这是第 13 周那句话。

绝不用活企鹅。Manly 种群不是实验室。

## 17. 蜜袋鼯夜间穿越

### 挑战
郊区树冠破碎后，蜜袋鼯只在夜、风小的时候才肯过空隙。风就是模式。杆/索 **只在夜间且风安全时伸出去** — 否则那是假邀请。有形基础设施，不给鼯戴追踪器。

### 非人类利益相关者
- **主 — 蜜袋鼯 / 松鼠鼯模型。** 需要一条只在能用时才存在的穿越。
- **鸮 / 猫。** 1.5 m 永久绳可能变成捕食者栖位 — **白天收回**。

### 构想
两根杆，1.2 m 空隙，可收回的线。

1. `RETRACTED` — 白天默认。
2. `NIGHT_CALM` — 夜照度 + 风 < 阈 → 线伸出。
3. `WIND_RETRACT` — 阵风 → 收回（不要假装有穿越）。
4. `OCCUPIED` — 线上 ToF/毫米波 → **不收回**（动物在绳上）。
5. `FAULT` — 失效 **停泊**；若占用则保持伸出；若空则收回。两种都写。

### 一句架构
夜 × 风 × 占用 → ESP32-S3 → 伸/收。风是模式。不给鼯戴追踪器。

```
 世界     夜                  风                     线上的身体
              │                   │                          │
 感知      BH1750              风速计或气象局            ToF / 毫米波
 融合                    ESP32-S3
 执行      MG90S 卷线 / 伸臂
 演示       风扇 = 风；夜照度；线上玩偶鼯
```

### 硬件栈
BH1750，风速计（模拟杯 **或** 第 8 周只用气象局风 — 「风就是界面」用廉价杯更诚实），沿线 LD2410 或 ToF，ESP32-S3，MG90S 卷线 **加** 弹簧或第二舵机，两根杆。

**安全。** 线不能在走廊里变成勒脖子的晾衣绳。演示放在标出的 1.2 m 湾里。

**BOM 差额。** 2 杆、线、可选模拟风速计、玩偶鼯。

### 软件栈

状态：`DAY_RETRACT` `NIGHT_EXTEND` `WIND_RETRACT` `OCCUPIED_HOLD` `FAULT`。

风滞后 30 s。占用覆盖风（不要把身体甩出去）。只用 API 风：缓存；夜间 API 挂了 **不要伸出**（防止假邀请），**除非** 有本地风速计。

## 18. 水龙晒岩

### 挑战
校园砂岩上的东部水龙被人惊下石头后，一时无法回温。不要惊吓。对人用近身学慢屏；石头上有龙体型时电机不得猛动。热舒适是给非人类的输出；人得到的是安静屏障，不是警报。

### 非人类利益相关者
- **主 — 东部水龙（*Intellagama lesueurii*）。** 留在石头上回温。
- **行人。** 慢、可读的屏障 — 不是稻草人。

### 构想
砂岩感石头模型；人在 3–5 m 时「屏」/叶片 **缓慢** 升起；石头上有龙体型热/身体则 **冻结**。

1. `BASK` — 红外或接触说石头上有龙体型；人远 → 什么都不做。
2. `SLOW_SCREEN` — 人在 3–5 m、石头 **空** → 10–20 s 升起。
3. `HOLD_IF_OCCUPIED` — 人靠近但石头上有身体 → **禁止电机**。
4. `HEAT_ASSIST`（可选，仅模型）— 深色石头已经在做这事；小加热伦理嘈杂 — **优先被动 PETG 热质量**。
5. `NIGHT` — 停泊。
6. `FAULT` — 停泊；永不猛动。

### 一句架构
人距 × 石上身体 × 照度 → ESP32-S3 → 慢屏障。电机不得惊吓。失效 **停泊**。

```
 世界     行人距离              龙体型身体 / 热           昼
              │                         │                        │
 感知      LD2410 距离               MLX90614 或 ToF           BH1750
 融合                    ESP32-S3
 执行      MG90S 慢叶 / 屏      （不对动物用警报器、不用灯）
 演示       石上玩偶龙 vs 人靠近
```

### 硬件栈
LD2410（距离），石面 MLX90614 或 ToF，BH1750，ESP32-S3，MG90S **软件限速**（2–3°/s），砂岩 PETG，玩偶/打印龙。

**不要警报喇叭。不要突然 180° 拍死。**

**BOM 差额。** MLX90614、砂岩打印、龙模型。

### 软件栈

`task_range` 100 ms · `task_rock` 200 ms · `task_lux` · `task_fsm` · `task_actuate`（斜率限制）。

状态：`EMPTY_IDLE` `BASK_HOLD` `SLOW_SCREEN` `NIGHT_PARK` `FAULT_PARK`。

若 `rock_occupied`，即使请求 `SLOW_SCREEN` 也冻结 `cmd.servo`。占用用红外差 **或** ToF。滞后，避免甩尾抖动。

### 实施计划

| 周 | 验收 | 谁 |
|---|---|---|
| 7 | 舵机 2°/s；硬编码禁止 | 2+3 |
| 8 | 可不用气象局；若要 Credit API：路上人体姿态 API（人 vs 空），红外仍管石头 — 仍不要 ChatGPT | 2 |
| 9 | 玩具在石上：人靠近 **不动**；空石：慢升 | 1 |

### Vision Pro

## 19. 䴢高潮栖绳

### 非人类利益相关者
- **主 — 鹊䴢 / 栖息滨鸟。** 不被打扰的高潮栖位。

### 一句架构

## 20. 针鼹停割桩

### 挑战
短吻针鼹白天在草坪和残林边觅食，在这个时间窗被割草机伤害，土壤也被压实。旗是给 **操作者** 看的，不是给动物穿的。振动 + 时钟 + 土壤。桩是 W9 有形物，并把 W10「可穿戴」逻辑反过来（该注意的是推割草机的人）。

### 非人类利益相关者
- **主 — 短吻针鼹（*Tachyglossus aculeatus*）。** 需要割草机在这块停下。
- **土壤 / 无脊椎。** 论文里的压实故事。
- **操作者。** 必须看见旗 / 感到触觉 — 不是割草时看手机 App。

### 构想
草皮托盘里的测量桩。

1. `QUIET` — 旗降。
2. `FORAGE_WINDOW` — 白天钟 + 土壤振动（针鼹一类） → 旗 **升**，可选给人的触觉带。
3. `MOWER_NEAR` — 毫米波大金属/快 → 旗紧急（更快升起），仍不对野生动物用警报器。
4. `NIGHT` — 降（针鼹夜里也会动；叙事按文献保持昼行）。
5. `FAULT` — 旗升（操作者要看得见）。失效 **升起**。

### 一句架构
振动 + 钟 + 土 + 割草机存在 → ESP32-S3 → 旗（和可选人用触觉）。可穿戴逻辑反转。

```
 世界     地面振动                昼钟 / 土              割草机 / 人
              │                           │                        │
 感知      压电 / IMU 模拟             BH1750 + DS18B20         LD2410
 融合                    ESP32-S3
 执行      MG90S 旗                   可选 BLE 触觉带（人）
 演示       拍草皮模型；玩具割草机靠近
```

### 硬件栈
桩里的压电片或 IMU（I2C MPU-6050），BH1750，可选土壤湿度（压实/湿度论文），朝「割草机」通道的 LD2410，ESP32-S3，MG90S 旗，PETG 测量桩，草皮托盘。可选 BLE 触觉到操作者 **手里的** 手机 — BLE 没做成，旗单独仍是 Pass。

**BOM 差额。** 压电或 IMU、鲜艳打印旗（操作者必须看见）、草皮托盘、玩具割草机。

**不要** 给针鼹戴追踪器。

### 软件栈

`task_vib` 10–20 ms（带通：拒绝连续割草机轰鸣 vs 嗅探脉冲 — 演示可以是「拍三下」）· `task_lux` · `task_radar` · `task_fsm` · `task_actuate`。
